Attività

Simuliamo il flusso di un’applicazione che permette ad un utente di ordinare pizze.

Per semplicità, non specifichiamo il gusto della pizza e sappiamo che tutte costano €8.


Organizzazione

Classe divisa in coppie, dove ciascun individuo ha un ruolo:

(A) Cassiere+app

Si interfaccia con l’utente, riceve la sua ordinazione (quante pizze vuole) e gli restituisce il totale da pagare.

(B) Cuoco

Riceve la comanda dal cassiere, controlla se può soddisfare l’ordine e restituisce il numero di pizze preparate. Se si verifica un problema durante la preparazione, si impegna comunque a restituire un numero.

Per il trio: riuscite a spezzare “cassiere” da “app”

 1import random
 2PREZZO_PIZZA = 8
 3pizze_disponibili = 5
 4
 5# 1. RILEVAZIONE (Cucina: controlla le regole e prepara le pizze)
 6def cucina(num_pizze):
 7    global pizze_disponibili
 8    forno_acceso = random.choice([True, False])
 9    if not forno_acceso:
10        return 0
11    if num_pizze > pizze_disponibili:
12        return 0
13    pizze_disponibili -= num_pizze
14    return num_pizze
15
16# 2. LIVELLO INTERMEDIO (Cassiere: calcola il conto, nessun controllo errori)
17def cassiere(num_pizze):
18    pizze_pronte = cucina(num_pizze)
19    totale = pizze_pronte * PREZZO_PIZZA
20    return totale
21
22# 3. GESTIONE (App Cliente: parla con l'utente e gestisce gli errori)
23def app(num_pizze):
24    conto = cassiere(num_pizze)
25    print("App -> Ordine confermato! Totale:", conto, "euro")
26

Le eccezioni in Python

Rilevazione
raise ValueError()

Istruzione utilizzata per lanciare un errore.

  • Dentro alle parentesi di ValueError() posso passare una stringa che indica il messaggio dell’errore
    • come il breve post-it di prima!
1def divisione(numeratore, denominatore):
2    if denominatore == 0:
3        raise ValueError("Non posso dividere per 0!")
4    return numeratore / denominatore

Gestione
try/except

Prova a fare qualcosa di rischioso in try, gestisci l’errore in except.

 1def divisione(numeratore, denominatore):
 2    if denominatore == 0:
 3        raise ValueError("Non posso dividere per 0!")
 4    return numeratore / denominatore
 5
 6try:
 7    risultato = divisione(3, 0)
 8    print("Ho diviso 3 per 0, ho ottenuto", risultato)
 9except ValueError as errore:
10    print("No! Qualcosa " +
11    " è andato storto durante la divisione:", errore)
